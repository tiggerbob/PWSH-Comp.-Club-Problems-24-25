Anyway, welcome to the Nanu Corporation. Since you'll be working in the drive-through...







Your job is to create a program that tallies the cost of items ordered at the drive-through and then create a report of total revenue. 
However, since many of our investors are earthly, the alien currencies need to be converted into Earth dollars respectively. The big
cats back home always want to know what going on up here. 

For example, if daily orders consisted of 2 Moncit Moon Pies, which each cost 8 Piddles, then you would need to count 16 Earth Dollars as the daily total.
Then return the total revenue collected that day.

**Input**
The first line contains _N_, the number of orders in a day.
Each _N_ line will first hold the cost _A_, and then the currency paid in, token _B_, than finally the item, _C_.

### Sample Input
```
3
1.5 Piddle Gurala oxo puffs
5 Piddle Assorted Maetti "meat"
1.5 Piddle Gurala oxo puffs
```
### Sample Output
```
64
```

### Sample Case Explanation:

As the order total was only 8 Piddles (1.5 + 5 + 1.5) and a piddle is 8 Earth Dollars, 8 * 8 = 64.
