Anyways, welcome to the Nanu Corporation. Since you’ll be working at the drive-through... 

Your job is to tally the cost of items ordered at the drive-through and then report the total revenue. However, since many of our investors are Earthly, the alien currencies need to be converted into Earth dollars. The fat cats back home always want to know what’s going on here...

For example, if the daily orders consisted of $2$ Moncit Moon Pies, which each cost $8$ Piddles, then you would need to tally $16$ Earth Dollars as the daily total, and then return the total revenue collected that day.

## Input Format
The first line contains $N$ $(0 \leq N \leq 10^{3})$, the number of orders in a day. <br>
Each of the next $N$ lines will first hold the cost of an item $P$ $(0 \leq P \leq 10^{4})$ and then the currency paid in $C$. $C$ will always be the capitalized singular form of currency (Example: Piddle). <br>
Finally, the currency will be followed by the item ordered. <br>

## Contraints
$0$ $\leq$ $N$ $\leq$ $10^{3}$ <br>
$0$ $\leq$ $P$ $\leq$ $10^{4}$ <br>

## Output Format
The total revenue in Earth Dollars

## Sample Input
```
3
1.5 Piddle Gurala oxo puffs
5 Piddle Assorted Maetti "meat"
1.5 Piddle Gurala oxo puffs
```
## Sample Output
```
64.0
```

## Sample Case Explaination

As the order total for the day was only $8$ Piddles $(1.5 + 5 + 1.5)$ and a Piddle is $8$ Earth Dollars, $8 \cdot 8 = 64$.
