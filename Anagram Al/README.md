# Anagram Al

Al works at Word Central. For his job Al had to tell whether two strings were anagrams of each other (whether they can be rearranged to form each other)

However, after a freak road rage incident Al has temporarily lost the ability to tell whether two strings are anagarams. Al's corporate overlords don't give him paid time off so he needs you to help him do his job.

From the given cases find the number of cases that are anagrams.

### Input Format

 The first line will contain an integer $i$ that represents the number of lines that follow. Each line represents a different case and contains two space seperated strings.
 
### Constraints

$0 \leq i \leq 10^{2}$ 

### Output Format

An integer representing the total number of cases that are anagrams.

### Sample Input
```
3
maps pams
regy ygre
fobz xobz
```

### Sample Output
```
2
```

### Sample Case Explanation:

The first 2 cases are anagrams because the strings can be rearranged to form each other. In the third case the strings cannot be rearranged to form each other so it is not an anagram.
