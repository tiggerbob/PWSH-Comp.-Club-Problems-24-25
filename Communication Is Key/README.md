# Communication Is Key

A galactic communication system operates between $n$ space stations, numbered $1$ to $n$. To optimize bandwidth, the communication system transmits data only on "prime stations." A prime station is one whose number is a prime number.
Your task is to determine the number of prime stations in the range from $1$ to $n$.

### Input Format

A single integer $n$, representing the number of space stations.

### Constraints

$1 \leq n \leq 10^{6}$

### Output Format

Print a single integer, the number of prime stations. 

### Sample Input 
```
10
```

### Sample Output
```
4
```

### Sample Case Explanation

The prime numbers from 1 to 10 are 2, 3, 5, and 7. This means there are 4 prime stations from 1 to 10.
