# Stranded

Oh no! Famous astronaut Edgar Allen Poe (change name later///) has been stranded on the moon’s surface a distance away from the closest moon base, and his oxygen is running out quickly! The environment around him is portrayed as a grid of numbers relative to the terrain’s elevation, and he can only move left, right, up, and down. Moving on flat terrain or to a lower elevation consumes one minute of oxygen, but moving to a higher elevation consumes two. Once Edgar Allen Poe (///) runs out of oxygen, he dies immediately, (even if he has reached the moonbase?). Is it possible for Edgar Allen Poe (///) to return to the moon base without injury?

### Input Format
The first line of input consists of an integer n denoting the number of test cases to follow.
For each of the n test cases, 
int m - minutes of oxygen left
ints R and C - width and height of the grid
the next C lines will consist of R integers representing each space on the grid’s elevation

### Output Format
Output “Yes” if it is possible for Edgar Allen Poe (change name later///) to make it back to the base alive or “No” if it is not.
