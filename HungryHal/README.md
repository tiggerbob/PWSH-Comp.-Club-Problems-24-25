# Hungry Hal

Hal is a hungry literary critic from the planet harzy. Species on this planet consume letters as sustenance. 

However, Hal is a picky eater so each of his meals are made of letters such that they can be arranged into palindromes and contain at least one vowel. 

Given a string of random letters, return the max number of meals Hal can make. Each meal must contain at least 3 letters, and a letter may only be used as many times as it appears. Hal also hates leaving out vowels so all vowels must be used.

### Input Format

 The first line will contain a string of random letters. 
 
### Constraints

The string will be of max length $10^{2}, and all vowels will be able to be used.

### Output Format

Output the number of meals Hal can create.

### Sample Input
```
odyuood
```

### Sample Output
```
2
```

### Sample Case Explanation:

In this case Hal can create the palindromes "dod" and "ouo" and has a remaning letter of y.
