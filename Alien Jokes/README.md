# Alien Jokes

Samuel Chester of Mars is meeting up with their new friend Caz, who lives on Neptune! To prepare, Samuel has written down some jokes, but they have two problems: they don’t know if Caz will find them funny, and they need to translate them from Martian into Caz’s native language, Neptunian. Luckily, you have the knowledge to help Samuel out. Neptunians have a particular sense of humor in that they only find jokes funny if they are palindromes in their original language. The translation from Martian into Neptunian is also simple, for both languages utilize only English alphanumeric characters (A-Z, a-z, 0-9). //// uhhh figure out. maybe base conversion of ascii characters, but there is sort of integer.parseint for that. ///alternatively for joke to be funny, it must include certain characters/be an anagram?? hm

### Input Format
The first line of input consists of an integer n denoting the number of test cases to follow.
For each of the n test cases, 
String s - one joke 

### Output Format
Output the translated Neptunian of only the funny jokes.
